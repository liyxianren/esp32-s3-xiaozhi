小智AI定时提醒功能 - 项目实施计划
📋 项目概述
项目名称: 小智AI定时提醒功能
实施方式: 设备端MCP工具
预计工时: 2-3小时（基础功能）
目标: 用户通过语音设置定时提醒，设备本地创建定时器，到期后主动提醒用户
🎯 功能需求
核心功能（MVP）
功能ID	功能名称	优先级	描述
F1	倒计时提醒	P0	用户："10秒后提醒我吃药"<br>设备：10秒后主动说"提醒：吃药"
F2	定时提醒	P0	用户："明天早上7点提醒我起床"<br>设备：明天7点主动提醒
F3	取消提醒	P1	用户："取消提醒"<br>AI查询并取消指定提醒
F4	查询提醒	P1	用户："我有哪些提醒"<br>AI列出所有待触发的提醒
高级功能（可选）
功能ID	功能名称	优先级	描述
F5	重复提醒	P2	用户："每天早上8点提醒我起床"<br>设备：每天8点重复提醒
F6	NVS持久化	P2	设备断电重启后恢复所有未触发的提醒
F7	提醒声音/振动	P3	播放本地音乐或振动提醒用户

参数:

验证 delay_seconds > 0
调用 ReminderManager::AddReminder(delay, message)
返回创建的提醒信息
验收标准：
 倒计时场景：delay_seconds 直接传递给ReminderManager
 定时场景：正确计算到目标时间的延迟（考虑跨天）

class ReminderManager {
public:
    struct ReminderInfo {
        uint32_t id;
        std::string message;
        uint32_t remaining_seconds;
    };
    
    std::vector<ReminderInfo> GetReminders() const;
};
实现逻辑：
std::vector<ReminderInfo> ReminderManager::GetReminders() const {
    std::vector<ReminderInfo> result;
    uint64_t now_ms = esp_timer_get_time() / 1000;
    
    for (const auto& reminder : reminders_) {
        ReminderInfo info;
        info.id = reminder.id;
        info.message = reminder.message;
        
        if (reminder.trigger_time_ms > now_ms) {
            info.remaining_seconds = (reminder.trigger_time_ms - now_ms) / 1000;
        } else {
            info.remaining_seconds = 0;
        }
        
        result.push_back(info);
    }
    
    return result;
}
验收标准：

 不修改内部状态（const方法）
